# راهنمای گذاشتن داشبورد فهیم فتحی روی GitHub Pages (فقط گیت‌هاب، بدون Firebase)

اطلاعات فقط روی گوشی خودت ذخیره می‌شود. برنامه بدون اینترنت هم کار می‌کند.

## گام ۱ ـ ساخت مخزن و آپلود
1. در github.com وارد حسابت شو و روی «New repository» بزن. نامی مثل fahim-dashboard بگذار و Public را انتخاب کن (در فایل‌ها هیچ داده‌ای از تو نیست).
2. «uploading an existing file» را بزن و همهٔ فایل‌های این پوشه را بکش (index.html، sw.js، manifest.webmanifest و سه آیکون). Commit changes را بزن.
3. Settings > **Pages** > Source: «Deploy from a branch» > شاخهٔ main و پوشهٔ root > Save.
4. بعد از یکی دو دقیقه آدرس `https://نام‌کاربری.github.io/fahim-dashboard/` ساخته می‌شود.

## گام ۲ ـ نصب روی گوشی
- آدرس را روی گوشی با اینترنت باز کن و یک بار صبر کن تا کامل بارگذاری شود.
- اندروید (Chrome): منوی سه‌نقطه > **Install app** یا Add to Home screen.
- آیفون (Safari): دکمهٔ اشتراک > **Add to Home Screen**. حتماً از آیکون روی صفحهٔ اصلی باز کن.

## گام ۳ ـ انتقال داده‌های فعلی
1. در آرتیفکت فعلی: «قیمت‌ها و پشتیبان» > «ساخت کد پشتیبان» > «کپی کد».
2. در اپ نصب‌شده: «قیمت‌ها و پشتیبان» > کد را بچسبان > «ورود اطلاعات».

## نکته‌های مهم
- اطلاعات فقط روی همان گوشی و همان مرورگر هستند. اگر داده‌های مرورگر پاک شود یا اپ را حذف کنی، ثبت‌ها از بین می‌روند. هر چند وقت یک بار در «قیمت‌ها و پشتیبان» کد پشتیبان را بساز و جایی (پیام‌رسان یا یادداشت) ذخیره کن.
- هر وقت فایل index.html را در گیت‌هاب عوض کنی، برنامه با اینترنت خودش به‌روز می‌شود.
